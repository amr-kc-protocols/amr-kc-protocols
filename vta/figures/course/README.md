# Ventilator Academy course visual kit

This directory contains the 27-graphic Academy visual kit generated for the
course and integrated into Modules 1–9. SVG is used where available for crisp,
responsive rendering; three medical illustrations are supplied as PNG.

## Placement

| Graphic | Lesson |
| --- | --- |
| 01–07 | Module 1: anatomy, physiology, and ventilator mechanics |
| 08–11 | Module 2: respiratory failure and capnography |
| 12–14 | Module 3: NIV and preoxygenation |
| 15 | Module 4: predicted body weight and tidal volume |
| 16 | Module 5: volume versus pressure targeting |
| 17–18, 20, 27 | Module 9: ARDS, auto-PEEP, TBI, and pediatrics |
| 19, 24 | Module 7: ventilator alarm response and DOPE |
| 21–25 | Module 6: LTV 1200 and transport readiness |
| 26 | Module 8: RASS |

## Course-specific safety edits

- Graphic 19 directs controlled backup ventilation with oxygen and PEEP while
  troubleshooting; it does not present uncontrolled manual ventilation as the
  universal response to every alarm.
- Graphic 26 does not label a universal RASS target. Sedation depth is
  individualized, and RASS cannot be interpreted during effective
  neuromuscular blockade.

Device/configuration graphics are conceptual teaching aids. The ventilator in
service, current manufacturer instructions, local protocol, and medical
direction remain controlling.
