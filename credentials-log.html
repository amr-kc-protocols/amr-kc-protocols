Status thresholds — measured from today against each expiration date. A person’s badge shows their worst credential.
Expired — past the expiration date
30 days — triggers the alert on the provider’s own view
90 days — get it on the calendar
Current — more than 90 days out
No records — nothing on file for that person at all
Manage data
Edit the roster here, then generate a new encrypted block and paste it into credentials-log.html. Nothing saves automatically — the file in the repo is the source of truth.
1 · Roster
One object per person, each with a creds array of {k, label, act, exp}. Dates are YYYY-MM-DD.
Tab- or comma-separated, header row required, one row per credential — paste the report exactly as it comes out. People already on the log are matched on Workday ID and have their credentials replaced; unknown IDs are added; anyone absent from the export keeps their record. The Activation Date column is ignored — renewal terms come from the credential type (2 years for AHA cards and Kansas, 5 for Missouri).
2 · Encrypt
Changing this changes the password staff use to open the full roster. It has no effect on personal lookup.
3 · Paste into the file
The UPDATED stamp is included in the block — nothing else in the file needs touching.
